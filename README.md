# 🌐 Catalin Ardelean Pop - Developer Portfolio

This repository contains the source code of my personal portfolio website, built with **React**.  
The site showcases my professional background, skills, and projects in the field of computer science and web development.

👉 **Live website:** [https://catalinpop.github.io/Portfolio/](https://catalinpop.github.io/Portfolio/)

---

## 🧭 Overview

My goal with this project was to create a **clean, fast, and responsive** online portfolio that reflects both my technical skills and my design approach.  
The website is entirely built with **React** and deployed automatically via **GitHub Pages**.

---

## 🚀 Features

- 🧠 Overview of my technical skills and tools  
- 💼 Professional and academic background  
- 💻 Showcase of personal and collaborative projects  
- 🌗 Dark and light mode support  
- 📱 Fully responsive layout  
- ⚡ Fast loading and optimized build for production  

---

## 🛠️ Tech Stack

- **React.js** – Front-end framework  
- **HTML5 / CSS3 / JavaScript (ES6+)**  
- **Node.js** + **npm** – Development environment and package manager  
- **gh-pages** – For automated deployment  
- *(Optional)* Framer Motion / TailwindCSS for animations and styling
